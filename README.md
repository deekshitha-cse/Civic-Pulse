# CivicPulse

A community-driven civic issue management system that helps citizens report public issues, intelligently groups duplicate reports, preserves community feedback , and dynamically prioritizes issues so authorities can address the most impactful problems first.

## Problem Statement 

Citizens often report the same civic issue multiple times, resulting in duplicate reports, scattered information, and inefficient issue management. Authorities spend unnecessary effort processing duplicate complaints instead of resolving them.

## Solution

CivicPulse consolidates duplicate reports into a single issue, allowing citizens to support existing reports rather than creating new ones. Community feedback, evidence, and dynamic prioritization help authorities identify and resolve the most impactful issues first.

## Features

- Report civic issues
- Support existing issues instead of creating duplicates
- One support per user per issue
- Add comments and additional descriptions
- Upload image evidence
- Dynamic issue prioritization
- Issue status tracking
- Authority dashboard for issue management
